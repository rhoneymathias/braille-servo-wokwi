# Projeto Braille com Servomotores – Raspberry Pi Pico

Este projeto utiliza 6 servomotores para representar letras do alfabeto Braille.

🔗 [Abrir no Wokwi](https://wokwi.com/projects/441750835768433665)

📖 Descrição

Representação do Alfabeto Braille com Servomotores
Este código em MicroPython simula o movimento de 6 servomotores para representar as letras do alfabeto Braille. Cada servo corresponde a um ponto da célula Braille, sendo acionado para posição alta (ponto levantado) ou baixa (ponto não ativo).

🔡 Regras de Representação

Cada letra é mapeada para um padrão de 6 pontos (0 = servo baixo, 1 = servo alto).

O projeto utiliza como exemplo a palavra "banana", exibindo letra por letra através do movimento dos servos.
